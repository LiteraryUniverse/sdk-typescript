# Security

Report a suspected vulnerability privately to security@literaryuniverse.com.
Include affected package/version, reproduction steps using synthetic data, and
the request ID when available. Keep API tokens and private writing out of reports.

The server remains responsible for credentials, scope/resource permissions,
versions, quotas, content validation and protected media access. SDK validation
improves diagnostics and does not authorize a write. Client names are reported
metadata. Tokens are never sent through redirects or stored in managed projects.
